# 前提条件与必要配置（展开）

这一份把 README 里那两节逐项展开，写清「为什么需要」和「怎么自己配」。所有值都用占位符，仓库里不含任何真实账号信息。

> ⚠️ **这一份不在 `tools/check_secrets.py` 的自动扫描范围内**（它在 `SKIP_FILES` 里，
> 因为整份都是讲解和占位符）。也就是说：**改动这一份之后，脱敏只能靠人眼过一遍**，
> 自检脚本不会替你兜住。改完请自己再读一次。

## 一、账号与登录态

### 1.1 账号本身

| 项 | 要求 | 说明 |
|---|---|---|
| 账号类型 | 华为云开发者账号，主账号或 IAM 用户均可 | 成长中心、社区、学堂、GitCode 绑定都是同一个身份体系 |
| 实名认证 | **必须已实名** | 微认证考试、开发者赛事报名会卡这一步 |
| GitCode 绑定 | 需绑一次 | 「Star 鸿蒙案例仓」任务要求先绑 GitCode；在鸿蒙实践中心任务卡的「管理绑定」里做 |
| 手机号 | 账号要绑一个能收短信的号 | 只有赛事报名表单用得到；平时不用 |

### 1.2 登录态：唯一必须由你本人建立的东西

浏览器把密码用操作系统级加密（Chromium 的 app-bound encryption）存着，外部脚本解不开，也读不到明文。**所以本项目所有脚本都默认「登录态已经由你手动建立好了」**，不碰账号密码、不做自动填充、不绕过验证码。

**每次开工第一步：检查登录态。**

```
打开 https://developer.huaweicloud.com/grow
看页面前 300 字：
  出现「登录/注册查看您的积分」  →  已掉线，先恢复
  出现你的昵称 / 积分数字        →  正常
```

**掉线了自己修，别去猜密码：**

1. 打开登录页
2. 点账号输入框，让浏览器自动填充（**不要手敲**，自动填充叠加手敲会把账号拼长一位）
3. 按 Escape 关掉下拉，点「登录」
4. 6 秒内 URL 跳到控制台 / 成长中心即成功

**容易掉线的高危操作**：云实验里的「一键登录」会切换成实验账号身份，可能连带清掉主账号会话。做完实验立刻回查一次登录态。

### 1.3 哪些环节必须真人出场

全流程只有三处，其余都能在自己环境里完成：

| 环节 | 为什么 | 怎么交接 |
|---|---|---|
| 建立 / 恢复登录态 | 浏览器加密，脚本解不开 | 你手动登录一次，之后长期保持 |
| 微认证**人脸识别** | 摄像头生物识别，必须真人 | 考前这一步自己过；之后答题可以照常 |
| 短信验证码 | 要真手机收 | 报名表单到这一步时自己填 |

> 微认证一次「免费激活」只有一次考试机会，人脸识别过了之后别中途切屏——考试页切屏 3 次会自动交卷。

## 二、运行环境

### 2.1 浏览器

| 要求 | 原因 |
|---|---|
| Chromium 系、能保持用户 profile | 登录态靠 profile 长期保存；每次换 profile 都要重新登录 |
| 支持在页面里执行 JS | 富文本编辑器、可见性筛选、原生 setter 都要用到 |
| 允许多标签、iframe | AI DevSpace 给的是 workspace 子域 iframe，单独开标签更稳 |
| 窗口不要最小化 | 最小化时截图会报错，部分计时任务在后台不计时 |

**判活别看端口**：这类浏览器不一定监听调试端口（9222/9223 关着也可能完全正常）。看进程数和它自己的任务空间是否还在。

**版本要对齐**：CLI 版本必须跟正在跑的浏览器版本一致，按可执行文件的 `ProductVersion` 取，别按安装目录里「最大版本号」取——安装目录常留多个版本，取错就报连不上 bootstrap。

### 2.2 Python

- 3.9+，标准库就够（`urllib`）
- 只用来跑 `tools/grow_tasks.py` 拿匿名任务清单
- 无第三方依赖，`pip install` 什么都不用装

### 2.3 Node.js（可选）

- 18+，只在你想自己写 `.mjs` 浏览器脚本时需要
- 不装也能读完整份笔记、也能手工做任务

### 2.4 网络与代理

| 需要能访问 | 用途 |
|---|---|
| `developer.huaweicloud.com` | 成长中心、活动、赛事、用户中心 |
| `bbs.huaweicloud.com` | 发文章、提建议 |
| `edu.huaweicloud.com` / `connect.huaweicloud.com` | 微认证、课程视频 |
| `harmonybp.developer.huaweicloud.com` | 鸿蒙实践中心三条任务 |
| `devstation.developer.huaweicloud.com` | AI DevSpace |
| `gitcode.com` | Star 案例仓、Agent 仓 |
| `devdata.huaweicloud.com` | 匿名任务清单接口 |

代理用环境变量 `HTTP_PROXY` / `HTTPS_PROXY`，**不要写进项目文件**。装依赖如果卡在代理，临时把这两个变量去掉再装就行。

## 三、配置文件逐项说明

复制 `config/config.example.json` → `config/config.json`，然后按下面改。`config.json` 已被 `.gitignore` 排除。

### 3.1 `sites` —— 入口 URL

```json
"sites": {
  "grow":         "https://developer.huaweicloud.com/grow",
  "harmony_tasks": "https://harmonybp.developer.huaweicloud.com/#practice-tasks",
  "blog_editor":  "https://bbs.huaweicloud.com/blogs/article",
  "cases":        "https://harmonybp.developer.huaweicloud.com/cases",
  "micro_list":   "https://edu.huaweicloud.com/certification/micro/list?grow"
}
```

这些是公开地址，一般不用改。平台改版导致跳转不对时，对照 `docs/03-站点结构与入口地图.md` 更新。

### 3.2 `browser` —— 浏览器环境

| 键 | 填什么 | 注意 |
|---|---|---|
| `profile_path` | 你自己的用户数据目录 | 每个账号一个 profile，别共用 |
| `space_name` | 任务空间名，随便起 | 用来把你的页面和别人的隔离，避免互相关页 |
| `bring_to_front` | `true` | 「浏览案例」在后台不计时，必须先置前台 |
| `settle_ms` | `9000` | SPA 首次渲染慢，5~6 秒常只出导航 |

### 3.3 `board` —— 飞书看板（可选）

```json
"board": { "enabled": false, "base_token": "<你的 base token>", "table_ids": { ... } }
```

- 默认 `false`。不配飞书，全部流程照常，只是没有可视化台账。
- 要用：飞书开放平台建一个自建应用，开多维表格权限，把 `base_token` 和四张表的 `table_id` 填进来。
- **四个表 ID 只是占位符**，别拿样例里的值去连真实表格。
- 台账结构建议：任务清单 / 积分看板 / 积分流水 / 每日打卡，流水表的去重键要带上「日期+来源任务+积分+备注前缀」，否则同一天发两篇会互相覆盖。

### 3.4 `timing` —— 节奏参数

| 键 | 建议值 | 依据 |
|---|---|---|
| `page_settle_ms` | `9000` | SPA 渲染实测 |
| `case_dwell_sec` | `40` | 「浏览案例」低于 40 秒不计时 |
| `star_verify_wait_min` | `4` | 从案例详情页进去 Star，1~4 分钟认 |
| `action_gap_ms` | `1200` | 两次操作间留间隔；**节奏太规整会明显不是人在操作** |
| `verify_hour` | `6` | 次日清晨核对到账，见 `docs/04` |

### 3.5 `credentials` —— AK/SK（只有发布作品才用）

```json
"credentials": { "mode": "env", "ak_var": "HUAWEICLOUD_SDK_AK", "sk_var": "HUAWEICLOUD_SDK_SK" }
```

- **只有 `env` 一个合法值**。工具只读环境变量，绝不读文件里的密钥。
- AK 是 20 位、SK 是 40 位，**两个都要**；只给 SK 会以为那是一整个密钥。
- STS 临时凭据只有 900 秒，过期重取即可，用完立刻销毁。
- 生成出来的 `params.json` / `sts-creds.*` 一律临时文件，用完删除，且必须在 `.gitignore` 里挡住。

## 四、自检清单（提交 / 运行前各跑一遍）

用这几条确认自己没把私货带进去：

- [ ] `config/config.json` 存在且**没有**被 git 跟踪（`git ls-files` 里看不到它）
- [ ] 全库搜不到手机号、IAM 用户名、社区昵称、实例 ID、base token、table id 真实值
- [ ] 全库搜不到 `AK`/`SK` 明文，也搜不到 `sts-creds` / `params.json` 这类实际文件
- [ ] 全库搜不到本机绝对路径（`C:\Users\...`、`D:\...`）
- [ ] 截图类文件没进仓库（`.gitignore` 已排除 `*.png` / `*.jpg`）
- [ ] 文档里没有「某个具体账号签到多少天」这种可反推身份的数据
- [ ] 环境变量 `HTTP_PROXY` 里若有代理，只在你本机，没写进任何文件

## 五、不做的边界

按合规和成本，这几类明确不碰，别在配置里找它们：

- **任何要花钱的**：买实验点、买资源、绑支付、AI 产品付费版
- **动真实云资源**：ECS 变配、安全组、DNS、OBS 桶——这些跟积分任务无关
- **自动生成并发布文章内容**：发文任务只认「原创且过审」，堆泛泛而谈的稿子过不了审也没价值
- **替他人代做需要实名的考试**：人脸识别那一步必须本人
