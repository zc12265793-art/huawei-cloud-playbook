# 积分任务操作手册

> 只写实测验证过的步骤。每条：入口 → 动作 → 成功判据 → 坑。
> 积分值和任务条数为 2026-11 实测，平台可能调整，以页面现状为准。
> 判定口径（哪些源可信、延迟多久）见 `04-平台机制与判定口径.md`，先读那份再动手。

---

## 0. 通用规矩

- **判断任务成败的顺序**：鸿蒙实践中心 `#practice-tasks` > 成长中心卡片 > 积分余额。
  成长中心卡片状态严重滞后，别拿它判断；余额涨了也不代表今天的任务都进了。
- ⚠️ 例外：「参与开发者赛事」这条相反——成长中心显示「去完成」是对的，报名不算分，要交参赛作品。
- **登录态检查（每次开工第一步）**：打开 `developer.huaweicloud.com/grow`，
  若前 300 字出现「登录/注册查看您的积分」= 已掉登录，所有需登录任务全部停摆。
  先按 `00-前提条件与配置.md` 的恢复步骤自己修。
- ⚠️ **掉线高危操作**：云实验里的「一键登录」会切换成实验账号身份，可能连带清掉主账号会话。
  做实验前确认主账号已登录，结束后立刻回查。
- **只有签到实时到账**，其余「按周期统一发放」。别用余额当天的成败判据。

### 0.1 台账（可选）

想有可视化台账，用一张飞书多维表格，建议四张表：任务清单 / 积分看板 / 积分流水 / 每日打卡。
具体表结构和去重键设计见 `02-实战难题与解法.md` 第 6 节。
不用飞书也完全可以，只是没有可视化台账。

## 2. 发布文章（每日 +60）

1. 打开 `bbs.huaweicloud.com/blogs/article`
2. 填标题 `#blogTitle`（≤64 字）、摘要 `#summary`（≤200 字）
3. 正文在 TinyMCE iframe：`iframe.tox-edit-area__iframe`（写法见 `05-通用前端操作技巧.md`）
   ```js
   const f = document.querySelector("iframe.tox-edit-area__iframe");
   f.focus(); f.contentDocument.body.focus(); f.contentDocument.body.innerHTML = "";
   // 然后粘贴正文全文
   ```
4. **不要碰标签框 `.tagator_input`**（会弹「不支持手动添加标签」并挡住按钮）
5. **不要点 `#submit-btn`**（点了没反应、无请求、无报错）
6. 直接调页面函数提交：`window.submitForm()`（内部 checkDevProSign → newBlogSubmit）
7. **成功判据**：跳到 `developer.huaweicloud.com/processcomplete?type=blog`，显示「提交成功…工作人员正在审核」

- 发布后进人工审核，成长中心任务不会立刻变「已完成」。
- 判「今天发没发」看「我的博客」页里有没有「发布于 今天」，别看成长中心。

### 2.1 内容怎么写才过审

- **必须原创、必须改写**，不能整段翻译、不能复制项目 README、不能 AI 生成的泛泛而谈。
- 每篇至少 3 个具体技术细节：具体函数名 / 关键参数值 / 真实报错或边界条件。
  范例：写「滑块拖不动」那篇，落点是 `touch-action: none`、`passive: false`、24px 阈值，过审和真实度都更好。
- 角度偏「实战踩坑」而非「概念科普」；读者是刚学 Python/JS 两三个月、能看懂代码但没做过项目的人。
- **改写姿势**：外部项目只作为「我这里用了这个」出现，文章主角是你自己的问题和取舍。
  结构：遇到什么问题 → 试过哪几种方案 → 各自死在哪 → 最后怎么选 → 踩了什么坑 → 什么场景它不够用。
  实测范例：素材是某个密钥管理项目，但文章写成《我的 API Key 散在 7 个 .env 里，试了三种方案才收拢》——
  主体是三种方案对比，那个项目只在最后作为采用方案出现，还写了「什么场景它不够用」。
- **去重**：同一素材一个月内不写第二篇，同一天只发一篇。台账里记下素材来源避免重复。

## 4. Star 鸿蒙案例仓（每日 +30）

**必须走这条路，否则平台不认：**

1. 确认已绑 GitCode：实践中心任务卡「管理绑定」里能看到你的绑定 ID
2. **入口两个，首选任务卡那个：**
   - **首选**：`#practice-tasks` 任务卡上的 **「前往 Star 案例仓」** 按钮 → 直达
     `gitcode.com/harmony-practice-center` 组织页 → 在组织页里点开目标仓
   - **次选**：`harmonybp.developer.huaweicloud.com/cases` → 点任一案例 →
     详情页点 **「本案例 GitCode 仓库」**
     ⚠️ 次选**只在同一标签页内跳转时有效**。如果点完是**新开了一个标签页**，来源就丢了，平台一律不认
3. 在仓页用 **JS 原生 click** 点 Star：
   ```js
   const g = document.querySelector('.repo-action-group--star');
   (g.querySelector('.status-btn') || g.querySelector('.status-btn__text')).click();
   ```
4. **成功判据**：按钮 `Star` → `Starred`、计数 +1、hook 到 `POST web-api.gitcode.com/api/v2/projects/<项目ID>/star`
5. 回 `#practice-tasks` 看：「前往 Star 案例仓」按钮消失、变「已完成」——**几分钟内**就认
   （各入口形态的实测延迟见 `04-平台机制与判定口径.md` 第三节）

**为什么必须这么走（对照实测）：**

- ✅ 任务卡「前往 Star 案例仓」→ 组织页 → 点仓 → **几分钟内**任务卡转「已完成」（2026-11-07 实测）
- ✅ 从案例详情页进且**同一标签页内跳转** → 01:33 点，01:37 任务卡转「已完成」
- ❌ 从案例详情页点链接但**新开了标签页** → star 成功、计数 +1、请求也发出去了，
  任务卡仍是「前往 Star 案例仓」（2026-11-07 实测，等 20 分钟没认）
- ❌ 直接打开仓库页 star → 请求发出成功（506→507），等 25 分钟仍不认
- ❌ 已 star 过的仓再点不算

**一句话**：判不判，看**来源参数有没有跟着过去**。同一个仓、同样的 click，
从哪个入口进、有没有被新标签页切断，决定了认不认。

**点击方式的坑：**

- 坐标点击、强制点击、完整事件链派发**全部无效**，不发请求；只有 `element.click()` 管用
- 仓库页里有多个 `.status-btn`（页面下方推荐列表），必须限定在 `.repo-action-group--star` 内
- 点前先读按钮文本，`Starred` 就是已 star，再点会取消
- 任务要求「每日 Star 不同项目」且不可取消

## 5. 体验 AI DevSpace（每日 +30）

> 这条判定不稳，做完了也可能一直显示「去完成」，**别据此报「已到账」**，交给次日核验判。

1. 从成长中心「每日体验 AI DevSpace」卡片的「去完成」进（**带 `?dc=` 来源参数才算**）
2. 等页面「正在配置实操环境」从 0 走到 **100% 环境配置完成**（约 3~5 分钟）
3. 页面会给出 workspace 子域 iframe，地址形如 `https://<容器ID>.workspace.developer.huaweicloud.com/`；
   单独开标签比在 iframe 里操作稳（主页面跨域拿不到 contentDocument）
4. 跳过引导，在 `.chat-input-editor`（contenteditable）里输入一句话并回车
5. **成功判据**：对话区出现这条消息和「任务执行」记录

### 用完释放容器

1. 页面顶部「剩余时长」有释放入口，触发后确认「释放后容器环境及数据将被销毁」
2. **成功判据**：跳回 `developer.huaweicloud.com/`，顶部剩余时长消失
3. 不要点账户菜单里的「退出登录」，会让登录态掉线
4. 体验版容器免费，页面原话：「体验版容器环境 3 小时后会释放，再次启动会创建全新容器」

## 6. 发布作品（每月 +200，每月只能领一次）

1. 准备一个单文件可运行的小作品（例：2048 单文件游戏）
2. 需要有效 AK/SK（AK 20 位、SK 40 位，只走环境变量 `HUAWEICLOUD_SDK_AK` / `HUAWEICLOUD_SDK_SK`）
3. 流程：解析域名 → 取 STS 临时凭据 → 生成封面（标题必须与作品名一致）→ 调发布接口
4. **成功判据**：接口返回 `#status=201` + `workId` + `workUrl` + `reward=success value=200`
5. 收尾必做：删掉含凭据的临时文件 `params.json`、`sts-creds.json`、`sts-creds.sh`
6. 本月已领过就不给分，别重复发；发布成功后成长中心**不会立刻加分**，`reward=success` 才是真信号

### 6.1 凭证的坑

1. AK 20 位、SK 40 位，**两个都要**——容易只拿到 SK（40 位看着像一整个密钥）
2. CLI 工具配置里的旧 AK/SK 可能已失效（`APIGW.0301 Unauthorized`）；用环境变量优先级更高
3. STS 只有 900 秒，过期报 `#status=401 GALLERY.AUTH.UNAUTHORIZED`，重取即可
4. 封面标题必须与作品名一致，改名就要重新生成封面
5. **含凭据的文件用完必须删**；`.gitignore` 要挡住 `sts-creds.*` 和 `out/params.json`，推仓库前 `git ls-files` 确认
6. 活动列表匿名可读：`GET gallery.developer.huaweicloud.com/open-web-guest/v1/gallery/camps?pageNo=1&pageSize=20&periodYear=<年>`
7. **发布接口只认 IAM 签名**，网页登录态（cookie）一律 401，别在登录态上浪费时间

## 7. 云声建议（被采纳 +60 / 被实现 +200）

1. `bbs.huaweicloud.com/suggestion` →「提建议」→ `suggestion/new`
2. 类型：`.types-item` 第三个 = **产品缺陷**（顺序：功能建议/用户体验/产品缺陷），选中加 `active`
3. 标题 `#suggestionTitle`、内容 TinyMCE
4. **关联产品（此前卡点，已解决）**：点 `.tagator_input` → 等 2 秒 → 输入关键词 → **等 3 秒**
   → 下拉出现 `.recent-tag.product-item`，点选目标项；选中后 `#submit-btn` 解除 disabled
5. 协议：先点页面空白处关掉下拉（否则下拉的 `<ul>` 挡住 `#agreementBox`）→ 点 `#agreementBox`
6. 点 `#submit-btn` → **成功判据**：「提交成功 感谢您提交的建议，华为云将会在 2 个工作日内完成预审」
7. **积分是「被采纳 +60」**：提交只入库，预审 2 个工作日 + 评估采纳后才给分

- 坑：提交失败后勾选状态会丢，必须重新勾再提交
- 坑：文本里不要有尖括号 `<id>` 这种，会被命令行当重定向符号
- 坑：「数据开小差」= 平台间歇故障，最小表单复测也失败就是平台问题，别反复重试

## 9. 微认证（每周 +200）

> **结案结论**：「微认证走不通」是错的。正确入口是**活动页免费激活**，绕开实验点墙。
> ⚠️ **唯一无法代做的环节：人脸识别必须真人**。激活、刷课、测验、答题都能在自己环境里完成，只有这一步要本人。
> ⚠️ **证书第 1 个自然日才发放**，成长中心 +200 要等证书入库才判定完成；
> 一次激活只有 1 次考试机会，**别重考**。

### 全链路（实测验证）

1. **入口（关键）**：活动页 `edu.huaweicloud.com/signup/<活动ID>`（"0元领云技术精髓开发者证书"），
   页内明写「所有微认证无需购买，点击『免费激活』即可」
2. **激活解锁考试**：点「免费激活」→ 弹窗"激活成功"→「进入考试」按钮从 disabled 变可点。
   **不再要求先完成实验**——这是绕开实验点的正道，5 个微认证任选一个都能这么走
3. 活动报名：填「学校/公司」= 个人开发者
4. 认证总览 `edu.huaweicloud.com/certificationindex`、我的课程 `edu.huaweicloud.com/my/course`
5. **刷课**：课程页四节视频，每节下面还有**子视频标签**，逐个播才算数。
   节状态读 `<img class="accordion-icon">` 的 title 属性，比「已学 %」可靠
6. **考试**：45 分钟 / 24 题（判断+单选+多选）/ 100 分制 / **70 分及格** / 错选漏选均不得分 / 题库随机抽题

   答题 DOM：`label.click()` 逐个验证 `input.checked`

## 11. 需要真人出场的环节（全流程只有这些）

| 环节 | 原因 | 怎么处理 |
|---|---|---|
| 华为云账号登录 | 浏览器加密，脚本解不开 | 手动登录一次，长期保持 |

### 11.1 登录态恢复五步

1. 浏览器 Profile 里已存账号密码（系统级加密，外部脚本解不开但页面能自动填）
2. 打开登录页 `auth.huaweicloud.com/authui/login.html`
3. 点账号输入框触发自动填充 → 校验隐藏字段里的账号和 password 长度
4. **不要用键盘 type 填**（会污染成末尾多一位）。按 Escape 关下拉，点最靠下的「登录」按钮
5. 6 秒内 URL 变回控制台 / 成长中心即成功

## 12. 云实验的账号隔离红线

- 入口：微认证详情页 → 实验练习 →「开始实验」（90 分钟，每天 1 次免费名额）
- ⚠️ **点「一键登录」后控制台里仍可能是你自己的账号，不是实验账号**——用它做实验会**真实扣费**，必须立即停手
- 正确做法（未验证）：先退出个人账号再用实验账号登录，或换独立浏览器 profile（会影响签到登录态）
- 结论：这步必须本人配合，别在自己的登录态下代做

## 13. 明确不做的

- AI 产品积分（换不了成长中心券，部分版本要钱）
- 任何要花钱、要买资源、要绑支付的
- 动 ECS / 服务器 / DNS / 安全组
- 社区成长值（论坛/博客那套）：**独立体系**，只能升等级拿勋章，换不了代金券，结论是不刷

## 14. 社区成长值（独立体系，结论不刷）

- 入口：`developer.huaweicloud.com/usercenter/mycommunity/grow`
- 与成长中心积分是两套，别混：成长值只能升等级拿勋章，换不了代金券
- 任务只有 6 条（「查看全部任务」是轮播箭头不是列表入口）：发文 +10 / 云声被采纳 +10 /
  云声预审通过 +5 / 报名线上活动 +3 / 评论文章 +3 / 推荐报名 +3
- 实测：「评论一篇文章 +3」实时到账；发文章 +10 当天不到账（疑审核后才结算，未验证）
- 结论：不重要，不专门刷
