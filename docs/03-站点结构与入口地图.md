# 站点结构与入口地图

> 华为云不是一个站，是十几个子站拼起来的，登录态互通但导航各不相同。
> 找任何入口先查这张图，不用重新探索。URL 都是实测可用的公开地址。

## 一、域名总览（先认门）

华为云不是一个站，是十几个子站拼起来的，登录态互通但**导航各不相同**。

| 域名 | 是什么 | 主要用途 |
|---|---|---|
| `www.huaweicloud.com` | 华为云官网 | 产品介绍、定价、文档、购买 |
| `developer.huaweicloud.com` | 开发者官网 | 成长中心、大赛、活动、用户中心、AI Shell |
| `console.huaweicloud.com` | 控制台 | 所有云资源管理（按 region 分区） |
| `account.huaweicloud.com` | 账号/费用中心 | 费用总览、订单、优惠券、续费、发票 |
| `bbs.huaweicloud.com` | 开发者社区 | 博客、论坛、云声建议、直播 |
| `edu.huaweicloud.com` | 华为云学堂 | 课程、微认证、考试、云实验 |
| `skills.huaweicloud.com` | 云 Skills 库 | Agent 技能市场 |
| `gallery.developer.huaweicloud.com` | 开发者作品展览馆 | 发作品、看排行榜 |
| `harmonybp.developer.huaweicloud.com` | 鸿蒙开发实践中心 | 鸿蒙案例、云端作业 |
| `hands-on-agent.developer.huaweicloud.com` | AI Agent 开发实践中心 | Agent 案例库、实践任务 |
| `devstation.developer.huaweicloud.com` | AI 开发者空间 | 免费用容器（体验版 3 小时） |
| `connect.huaweicloud.com` | 课程学习平台 | 视频播放页（学堂课程跳这里） |
| `lab.huaweicloud.com` | 云实验 | **会跳转到 `edu.huaweicloud.com/lab/`** |
| `www.chaspark.com` | 茶思屋 | 学术/技术交流、专利检索 |

**区域（region）参数**：控制台和费用中心都带 `?region=xxx`，例如中国-香港是 `ap-southeast-1`。
区域名以实例名和控制台实际显示为准，别凭印象记——`ap-southeast-1`（香港）、`ap-southeast-3`（新加坡）很容易混。

## 二、开发者官网有两套导航（重要，别找错）

同一个 `developer.huaweicloud.com`，不同页面用的导航栏不一样：

**新版（实践中心、作品馆等页面用）**
```
开发者 | 实践中心 | AI 开发者空间 | Skills中心 | 开放能力 | 大赛 | 学堂 | 成长中心 | 茶思屋
```

**旧版（大赛列表、活动页、社区、云声等页面用）**
```
开发 | 活动 | Programs | 社区 | 学堂 | 大赛 | 支持 | 茶思屋
```

**这是什么坑**：在两套导航的页面之间跳，会发现「活动」入口时有时无、「社区」在某些页找不到。不是 bug，是版本没统一。找入口时按当前页面属于哪套来找。

### 3.3 费用中心 `account.huaweicloud.com/usercenter`

基础格式：`/usercenter/?region=ap-southeast-1#/userindex/<页面>`

| 页面 | 路径 | 实测 |
|---|---|---|
| 总览 | `#/userindex/allview` | ✓ |
| 我的订单 | `#/userindex/myOrder` | ✓ |
| 资源包 | `#/userindex/myResourcePackage` | ✓ |
| 续费管理 | `#/userindex/renewalManagement` | ✓ |
| 合同管理 | `#/userindex/contractCenter` | ✓ |
| 发票管理 | `#/userindex/invoiceCenter` | ✓ |
| 导出记录 | `#/userindex/exportRecords` | ✓ |
| 成本中心 | 另一个域：`/costmanagement/?region=xxx#/cost/overview` | ✓ |

**坑**：直接拼 URL 有很大概率被重定向回 `#/userindex/allview`（总览）。用户中心（订单管理/资金管理/账单管理/优惠折扣）这几个是单页内部切换，**地址栏不变**，必须点左侧菜单。优惠券从总览页的「代金券」卡片点「立即使用」进。

**续费页**：从实例卡片点「续费」→ 弹确认框 → 确定 → 跳
`/usercenter/?locale=zh-cn&agencyId=...&region=...&## /batchrenewal?subscriptionIds=<订单号>`

## 六、账号标识（同一个人在不同子系统里显示不同名字）

同一个账号，在华为云不同子系统里显示的名字可能不一样——这很容易让人以为看到的是别人的账号。
常见的几类标识：

| 场景 | 通常显示什么 |
|---|---|
| 控制台 / 费用中心右上角 | IAM 用户名 |
| 开发者中心接口里的账号名 | 带前缀的账号名 |
| 社区昵称（博客、论坛、评论） | 社区昵称 |
| 作品展览馆作者名 | 同 IAM 用户名 |

**去哪核对**：`console.huaweicloud.com/iam/?locale=zh-cn#/mine`（「我的凭证」页）列了 IAM 用户名、
账号名、IAM 用户 ID、账号 ID，看到陌生名字先跟这一页对照。这一页同时也是访问密钥（AK/SK）管理入口。
