# 华为云开发者成长中心 · 实战笔记

把「每天把成长中心能拿的积分拿全」这件事跑通之后，留下的一份可复用记录：有哪些任务、每个任务怎么才算真完成、平台的判定有多慢、以及踩过的坑和解法。

这不是一个装好就能自动刷分的工具箱。它是一份**方法笔记 + 一组最小工具**：看懂之后，你自己决定用哪套浏览器环境、哪些任务值得做。仓库里没有任何账号、密钥、手机号、内部路径。

---

## 一、前提条件

按顺序准备，缺一项后面就跑不通。

| # | 前提 | 为什么必须有 | 不准备的后果 |
|---|---|---|---|
| 1 | **一个华为云开发者账号，且已实名认证** | 签到、发文、微认证、赛事报名都要求登录态；微认证考试还要实名 | 大部分任务按钮点不动，或提示先实名 |
| 2 | **登录态由你本人建立并长期维护** | 浏览器把密码用系统级加密存着，外部脚本解不开；本项目所有脚本都**不碰账号密码** | 登录态一掉，所有需登录任务全部停摆 |
| 3 | **一个能保持会话的 Chromium 系浏览器** | 大量页面是 SPA、富文本编辑器、iframe，静态请求拿不到 | 富文本写不进值、提交按钮点了没反应 |
| 4 | **Python 3.9+** | 跑 `tools/` 下的匿名接口工具；标准库即可，没有第三方依赖 | 只是拿不到任务清单，不影响手工做任务 |
| 5 | **Node.js 18+**（可选） | 如果你要自己写浏览器操作脚本，用 `.mjs` 跑 | 只是不能跑自写脚本 |

**两个可选组件**，跟「能不能拿分」无关，只影响有没有台账和能不能报名：

| 可选 | 什么时候才需要 |
|---|---|
| 飞书自建应用 + 一张多维表格 | 想有积分看板、每日流水、次日核验记录时。不用飞书完全可以，只是没有可视化台账 |
| 手机短信验证码通道 | 只有「开发者赛事报名」表单要短信码；不做赛事就不必准备 |
| IAM 访问密钥 AK/SK | 只有「发布作品到作品馆」这一条月度任务用得到，且**只走环境变量，绝不写进文件** |

### 网络前提

- 需要能访问这些域：`developer.huaweicloud.com`、`bbs.huaweicloud.com`、`edu.huaweicloud.com`、`harmonybp.developer.huaweicloud.com`、`gitcode.com`、`devdata.huaweicloud.com`
- 需要代理时，在自己的环境变量里配 `HTTP_PROXY` / `HTTPS_PROXY`；**本项目不写死任何代理地址**
- `devdata.huaweicloud.com` 的任务清单接口是匿名的，不需要登录态

## 二、必要配置

仓库里 `config/config.example.json` 是完整样例。**复制成 `config/config.json` 再改**，这个文件已被 `.gitignore` 排除，不会误提交。

| 配置项 | 作用 | 默认值 / 怎么填 |
|---|---|---|
| `sites.*` | 各任务入口 URL | 已填好公开地址，一般不用改；平台改版时才更新 |
| `browser.profile_path` | 浏览器用户数据目录 | 填你自己的 profile 路径，用来保持登录态 |
| `browser.space_name` | 任务空间名 | 随便起，用来把你自己的页面和别人的隔离开 |
| `board.enabled` | 是否启用飞书看板 | 默认 `false`；不配飞书就保持关着 |
| `board.base_token` | 飞书多维表格 token | 占位，只在 `enabled=true` 时要填 |
| `board.table_ids.*` | 四张表的 table id | 占位，同上 |
| `timing.page_settle_ms` | SPA 页面等待渲染时间 | `9000`（实测 5~6 秒常常只渲染出导航） |
| `timing.case_dwell_sec` | 「浏览案例」任务停留秒数 | `40`（低于这个数平台不计时） |
| `timing.star_verify_wait_min` | Star 后回查任务卡的等待分钟 | `4`（实测 1~4 分钟就认） |
| `timing.action_gap_ms` | 两次操作之间的间隔 | `1200`；别设成 0，节奏太规整容易触发风控 |
| `logging.output` | 日志输出位置 | 默认只输出到屏幕，不落盘 |
| `credentials.mode` | AK/SK 提供方式 | 固定 `env`，即只读 `HUAWEICLOUD_SDK_AK` / `HUAWEICLOUD_SDK_SK` 环境变量 |

**一条硬规矩**：`config.json`、任何含 AK/SK / cookie / token 的文件，都在 `.gitignore` 里。`credentials.mode` 只有 `env` 一个合法值——发布作品的 STS 凭据只有 900 秒有效期，用完即弃，落盘没有任何收益。

逐项的展开说明、以及每个配置为什么是这个值，见 [`docs/00-前提条件与配置.md`](docs/00-前提条件与配置.md)。

## 三、快速开始

```bash
# 1. 拿到任务清单（匿名接口，不需要登录）
python tools/grow_tasks.py 60

# 2. 打开成长中心，确认登录态正常
#    https://developer.huaweicloud.com/grow
#    页面前 300 字若出现「登录/注册查看您的积分」→ 登录态已掉，先恢复

# 3. 按 docs/01 逐条做任务，用「成功判据」判断，不要用余额判断

# 4. 第二天再核对到账（docs/04），不要当天就下结论
```

**先读 [`docs/04-平台机制与判定口径.md`](docs/04-平台机制与判定口径.md)**。这套东西最容易出错的地方不是操作，是**把「平台还没结算」误判成「任务没做成」**，然后重做一遍、甚至把已经通过的考试重考。

## 五、必读：三个判断前提

写进代码或台账之前，先把这三条记住，否则数据一定是错的。

1. **只有签到实时到账。** 其余任务的积分「按任务周期统一发放」，页面原话如此。余额没变 ≠ 任务没做；任务卡「已完成」≠ 积分已到账。
2. **判据源是有分工的。** 鸿蒙三条任务看鸿蒙实践中心 `#practice-tasks`（最实时）；DevSpace / Agent 仓任务看成长中心卡片；发文章看「我的博客」里「发布于 今天」；**成长中心卡片严重滞后，不能单独当判据**。
3. **「做了平台没认」有两种，动作相反。** 真没认 → 换做法重试；认了但慢 → 什么都不用做，等。查 `docs/04` 的延迟表，没超过上限就一律写「待结算」，不能写「假完成」。

## 六、FAQ

**Q：为什么没有那些自动化脚本？**
原始探索期有 1000 多个一次性脚本和大量截图，它们绑死在某台机器的某个浏览器 profile 上，没有复用价值，还夹着账号信息。这个仓库保留的是**能迁移的部分**：任务清单、入口、成功判据、判定口径、通用前端技巧。想跑自动化，拿 `docs/05` 的技巧配合你自己的浏览器环境重写即可。

**Q：公开这个会不会影响我的账号？**
仓库里没有任何账号标识：手机号、IAM 用户名、社区昵称、实例 ID、飞书表格 token、AK/SK 全部剔除了。提交前请再跑一遍 `tools/check_secrets.py`（若你自建）或按 `docs/00` 末尾的自检清单核对自己的 `config.json`。

**Q：任务周期会变吗？**
会。积分值、任务条数、入口 URL 都是 2026-11 实测值，平台随时可能改。发现对不上，以页面现状为准，顺手提个 PR 更新。
